# Assets

Images for the README and the docs. Nothing here is generated by a build step, and nothing loads an external script, stylesheet or font. Each SVG carries a `<title>` and `<desc>` for assistive technology and paints its own opaque canvas, so one file renders the same on GitHub's light and dark themes.

This directory is unrelated to the server's `/docs/assets/` HTTP route, which serves the vendored Swagger UI files from `src/titanos/web/`.

## Palette and type

The diagrams still use the neutral palette of the 28 Sep 2026 Studio theme (the `--hm-*` tokens Studio had then); they have not been recoloured to the current "Cabinet" tokens that [Studio design](../STUDIO_DESIGN.md) lists. Surfaces are flat fills with 1 px strokes, corners are 4 px, and there are no gradients, shadows, letter-spacing or uppercase labels:

| Role | Value |
|---|---|
| canvas | `#111214` |
| surfaces | `#17181B` (boxes), `#1F2024` (bars) |
| decorative rule | `#2A2C30` (bar strokes) |
| control border | `#6C7078` (box and frame strokes) |
| text | `#ECEDEF`, secondary `#B9BCC3`, muted `#8B8F98` (also the edges and arrowheads) |
| lime | `#90E301`, only for a "yes" branch or a readiness marker |

Violet appears only inside the identity marks; the diagrams carry none (Studio itself now uses violet for its bay frames and plates). Text uses the default `body` font stack from the same file (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Noto Sans`, `Arial`, then `sans-serif`) at 20 px for the title, 13 px for section labels and the subtitle, 12 px for box titles and 11 px for everything else, weights 500 and 600 only; the CJK stack that Studio switches to for Japanese and Simplified Chinese is not needed here. Labels were sized at 0.55 em per character plus box padding, so they stay inside their boxes when a viewer substitutes a wider font.

## Studio display face

Studio's plates, numerals and RUN button use **Chakra Petch** by Cadson Demak (SIL Open Font License 1.1). The upstream files are `ofl/chakrapetch/ChakraPetch-SemiBold.ttf` and `ChakraPetch-BoldItalic.ttf` from the google/fonts repository (with its `METADATA.pb` and `OFL.txt`), subset to Latin and converted to WOFF2 as `src/titanos/web/fonts/ChakraPetch-SemiBold.woff2` (7,728 bytes, SHA-256 `14c8d931ddaeb57af1f0df5f08086751ee7eda0317c1249c66b86105d9546707`) and `ChakraPetch-BoldItalic.woff2` (8,320 bytes, SHA-256 `1e45ca3b9b53b82029dad1c7281468f6fd6b2f404bfac4a794caa2efe6377971`), with the licence beside them as `fonts/OFL.txt`. The server serves only six named files under `/ui`, so `style.css` carries both faces inline as `data:font/woff2` URIs and ends with the full OFL text; `tests/check_studio_design_ui.js` checks that the inlined data equals the two files and that the licence is present. The fonts are not loaded from any other origin. The three files are catalogued like the Swagger UI files in `tools/licenses/vendored_assets.json` (upstream TTF hashes, the `m4rc1e/Chakra-Petch` source commit from `METADATA.pb`, per-file SHA-256), with the licence retained as `tools/licenses/chakra-petch-1.000-OFL.txt`; the wheel and sdist carry them as package data, and the frozen build ships them under `_internal/titanos/web/fonts/` and refuses to package if any differs from its catalogued hash (`tests/check_docs_offline.py`).

Retake them whenever Studio copy or the theme changes. Start a server as above with an empty scratch `TITANOS_HOME`, register small models and configure a loopback mock upstream (or a real provider of your own), open `http://127.0.0.1:<port>/` in a Chromium browser at the viewport above, keep Simple and English, run one chat, capture, then stop the server and delete the scratch home. Keep each file under 400 KB by downsampling, not by reducing colours. Do not capture the "Connecting…" state, Advanced mode's device lists, or anything that names your own hardware, paths or keys.

## Hygiene

These files travel with both public source copies (the sdist through `MANIFEST.in` and the native `SOURCE/` copy), and `tests/check_public_export_hygiene.py` scans SVG and Markdown text. Labels use `~/.titanos`, `TITANOS_HOME`, `/path/to/...` and `127.0.0.1`, and never a machine name, a user-profile path, a private address or a drive-rooted lab path. PNG is skipped by the scan, so check a screenshot by eye for the same things before adding it.
