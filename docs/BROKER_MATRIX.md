## Legend

States:

- `pass`: every cited test id exists in the test source and passed in the embedded run record (results file); all broker checks run loopback-only against mocks, fakes or an httpx MockTransport, so a pass without live evidence is labelled pass (mock)
- `live-pass`: a live evidence id from the live evidence file names this cell (the mock evidence stays cited beside it)
- `na`: not applicable, with the reason (a refusal the code makes on purpose, or a combination the design excludes)
- `untried`: no check cites the cell, or the cited test was skipped on this host; the reason says which

Labels: `pass (mock)` (this row was driven by a cited test), `pass (mock, adapter column)` (shown as `pass~` in the grids; proven through the column reference row on the same adapter code), `live-pass`, `na`, `untried`.

Modes:

- `P`: passthrough: the profile serves the surface natively (model rewritten, credential swapped, bytes streamed through)
- `T`: translated by the adapter through the canonical IR (broker/translate), incremental for streams
- `L`: local: the unchanged local route answers
- `L*`: local bridge: the request is re-encoded as an OpenAI body and answered by the local OpenAI route
- `na`: not served: 400 broker_capability_unavailable before egress (or the refusal the reason names)

Proof:

- `profile`: a cited test drove this profile row itself (the reference row of its adapter column, or a profile-row test)
- `column`: proven for the adapter column through its reference profile row on the same adapter code; this profile row differs only in data (base URL, auth template, ParamMap, surfaces) and is covered by the profile table consistency test

Adapter columns:

- `OAI`: OpenAI-compatible adapter (cloud and router rows)
- `AZ`: OpenAI-compatible adapter, azure_openai row (URL template, api-key)
- `ANT`: Anthropic Messages adapter
- `GEM`: Gemini adapter
- `XI`: ElevenLabs adapter
- `OLC`: Ollama native adapter (ollama_cloud)
- `SY`: split-protocol router row: OpenAI-compatible adapter with the Anthropic surfaces passed through natively; translated cells use the OAI column evidence

Cell ids:

- provider: `<surface>|<profile>|<off|on>`
- local: `<surface>|local|<off|on>`
- catalog: `<surface>|catalog`
- stage: `<surface>|cloud[:<task>] or <area>|<scope>`
- error: `error:<class>|<adapter>`
- envelope: `envelope:<rendering>|<protocol>`
- role: `role:<role>|<behaviour>`
- feature: `feature:<area>.<name>`

Profiles documented as not registered (absent, not stubbed): `aws_bedrock`, `vertex_ai`, `azure_entra`, `cohere_v2`, `deepgram`, `cartesia`, `stability`, `openai_realtime`, `openai_files_batches`, `elevenlabs_stream_input`.
